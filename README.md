# Roda Example Project

A simple example project using the Roda web framework for Ruby.

## Description

This project demonstrates the basic usage of Roda, a routing tree web framework for Ruby.

## Installation

```bash
bundle install
```

## Usage

```bash
rackup
```

## Features

- Lightweight routing system
- Simple configuration
- Easy to understand structure

## Requirements

- Ruby >= 2.5.0
- Bundler
